25 Page Script

A mobile application for discovering and sharing film scripts. Upload your original screenplays and connect with fellow writers and filmmakers.

Main Features

  • Phone number based registration
  • OTP verification via SMS
  • Upload and share your scripts
  • Browse scripts by genre
  • React and comment on scripts

SMS Usage Policy

SMS is used strictly for transactional purposes such as login and registration OTP verification. Messages are sent only after explicit user request inside the mobile application. No promotional messages are sent.

Privacy

User phone numbers are used only for authentication and are never shared with third parties.
